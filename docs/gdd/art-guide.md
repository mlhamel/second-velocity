# Art Guide

[active] — the entry point for contributing art

The current art is placeholder-grade: every texture under `assets/textures/`
was generated by `ops/generate_placeholder_art.py` (pixel-art generator v2,
ADR-0016). Replace the files, keep the names, canvas sizes, and content
footprints, and the game picks them up automatically.

## How art reaches the game

1. Content files in `content/` reference art by relative path:
   `sprite: Some("textures/ships/shuttle.png")` in a ship or planet
   definition, or `icon: Some("textures/outfits/light-blaster.png")` on an
   outfit / port commodity entry (paths are relative to `assets/`).
2. Pack validation (`cargo test -p sv-data`) fails if a referenced file
   is missing — no dangling art references, ever.
3. The client loads the PNG at spawn. If a definition has no `sprite` field,
   the game falls back to a procedural texture generated at the same native
   size, so content works before art exists.

## Rendering rules (ADR-0016)

- Textures sample **nearest-neighbor**; one texture texel renders as one
  world pixel. Draw content at the footprint listed below, centered in the
  canvas, and it appears 1:1 in game.
- Shop icons (~20 px) and chief portraits are the exception: they load with a
  linear sampler because they are downscaled heavily.
- The camera is HDR with bloom: sprite colors above 1.0 (over-bright, set in
  code for suns, weapon bolts, explosions, hit flashes) bloom into glow.
  Keep authored art inside the normal 0–1 range; glow is code's job.

## Conventions

| Kind | Path | Canvas | Content footprint | Notes |
|---|---|---|---|---|
| Ship | `assets/textures/ships/<ship-id>.png` | 128×128 | Light 36, Medium 48, Heavy 68, Capital 92 (per `ShipSize`) | **Faces +x (east).** Top-down, transparent background |
| Planet | `assets/textures/planets/<planet-id>.png` | 180×180 | full canvas (renders at exactly 180 px) | Natural colors; no tint applied |
| Station | `assets/textures/stations/<id>.png` | 128×128 | ~88 px centered docking ring | Station content can select its own sprite |
| Star | `assets/textures/stars/corona.png` | 128×128 | disc 30%, dithered corona falloff to 48% of canvas | Upscaled ~3.75× radius; falloff is calibrated to the 1.8× heat zone |
| Black hole | `assets/textures/black-holes/accretion.png` | 128×128 | horizon disc 25%, dithered ring to 48% | Upscaled 4× radius |
| Chief | `assets/textures/chiefs/<planet-or-station-id>.png` | 128×128 | bust portrait | Displayed in the docking encounter panel (linear sampled) |
| Commodity | `assets/textures/commodities/<commodity-id>.png` | 128×128 | ~96 px centered, chunky shapes readable at 20 px | Market row icon (linear sampled) |
| Outfit | `assets/textures/outfits/<outfit-id>.png` | 128×128 | ~96 px centered | Outfitter row icon (linear sampled) |

- RGBA PNG, transparent background
- Authored ship sprites render the full 128×128 canvas at 128 world px
  (texel-perfect), with the `ShipSize` content footprint centered; untextured
  fallbacks are per-size procedural hulls rendered at `ShipSize` world size
  (36/48/68/92 px), tinted by ship kind
- File name should match the content id — makes replacement obvious

## Pixel-art style (generator v2)

- Limited palettes: a 4–6 shade ramp per faction — terran (steel blue),
  vellari (cream/gold), sylph (teal green), korath (rust red-brown),
  auroran (burnt orange) — shared by the generator and `kind_color` in
  the client
- 1 px dark outlines on silhouettes; light from upper-right (+x, −y)
- Bayer-dithered shading ramps and stepped glow bands (no smooth gradients)
- Engine nozzles at −x, cockpit glints near +x; ships face +x

## Skies

Every star system gets a deterministic generated backdrop
(`crates/client/src/sky_gen.rs` + `visuals.rs`) — no image assets needed.
Seeds derive from the system id, so every player sees the same sky for the
same system:

- a dark per-system clear color (HSL-tinted from the system id)
- two parallax star layers (fast + slow, warm/cool star tints)
- three nebula accent puffs per system (HSL-tinted, dithered)

A richer deep-space pass (bands, clusters, distant galaxy) is queued for a
later graphics phase; NASA-imagery backgrounds stay rejected
(`docs/ideas/2026-10-12-real-space-skies.md`).

## Regenerating placeholders

```bash
python3 ops/generate_placeholder_art.py --force
```
