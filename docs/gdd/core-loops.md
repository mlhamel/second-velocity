# Core Loops

[active]

The game is built on four interlocking loops. Everything else hangs off them.

## 1. Trading (minutes)

Buy low, sell high between worlds and stations. Each docking port has its own
commodities and prices. Money buys better ships and equipment.

## 2. Missions (tens of minutes)

Offered by planet chiefs and station masters on docking (alongside resource
offers and tribute demands): delivery, bounty hunting, and timed contracts (see
[encounters.md](encounters.md)). Reputation with factions opens deeper story
arcs.

## 3. Combat (seconds)

Real-time, top-down 2D. Juggle a single energy pool between weapons, shields,
and engines. Escape is always an option — fuel for hyperspace is a combat
resource.

## 4. Shared-universe meta (days/weeks) — MMO layer

Every player's trading moves the shared economy. Every player's combat shifts
the faction war. The galaxy is persistent and reacts to everyone.

## Design pillars

1. **Freedom**: the game never pushes you anywhere. Pirate, trader, mercenary,
   faction hero.
2. **Consequence**: reputation opens doors and closes others.
3. **Shared fate**: one galaxy, everyone's actions matter.
4. **Moddable lineage**: content is data; shards can run custom universes.
